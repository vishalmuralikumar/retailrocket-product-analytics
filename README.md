# Retailrocket Product Analytics

A retail product analytics project using **Snowflake, dbt, Python, and Power BI** to analyze customer behavior, product performance, conversion funnels, and retention.

The project includes statistical analysis, data quality testing, data governance, and a **Streamlit AI assistant powered by Snowflake Cortex Analyst** that answers questions using SQL and displays query results.
